# Node E-Commerce Use Case

## What it is
An early Node.js and Express e-commerce backend. It is the seed that later became the Realtime Commerce Platform.

## What is in the repo
- Express entry in index.js.
- Controllers, Models, Routes, and Utils folders for the shopping domain.
- TestFiles for manual API checks.
- No frontend. This was the API layer only.

## What it covered
Typical shopping flows: product and cart style endpoints, order-related backend logic, and a simple service layout.

## What came next
The Postman collection and some setup were lost. Instead of patching this repo, it was rebuilt as realtime-commerce-platform with Next.js storefront and admin apps, GraphQL BFF, Redis, search, recommendations, and a .NET fulfillment service.
